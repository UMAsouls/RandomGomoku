# 五目並べGUI - 人間 vs MCTS

このプロジェクトは、Monte Carlo Tree Search (MCTS) アルゴリズムを使用したAIプレイヤーと人間が対戦できる五目並べGUIアプリケーションです。

## ファイル構成

### 基本版
- `gui_human_vs_mcts.py` - 基本的なGUIアプリケーション
- `run_gui_human_vs_mcts.bat` - 基本版起動用バッチファイル

### 改良版
- `gui_advanced_human_vs_mcts.py` - 機能拡張版GUIアプリケーション
- `run_advanced_gui.bat` - 改良版起動用バッチファイル

## 機能

### 基本版の機能
- **基本的な五目並べ対戦**: 人間（黒）vs MCTS AI（白）
- **リアルタイム対戦**: マウスクリックで石を置く
- **プレイアウト数調整**: MCTSの思考時間を調整可能
- **ゲームリセット**: いつでもゲームを再開可能
- **視覚的フィードバック**: 最後の手のハイライト表示

### 改良版の追加機能
- **ヒント機能**: AIが推奨する手を表示
- **詳細設定**: 
  - ポリシー選択（ランダム/改良版）
  - C_PUCT値の調整
  - 並列スレッド数の調整
- **統計表示**: 勝敗記録の表示
- **改良されたAI**: 簡単な評価関数による強化されたプレイ

## 使用方法

### 起動方法

#### 方法1: バッチファイル使用
```bash
# 基本版
run_gui_human_vs_mcts.bat

# 改良版
run_advanced_gui.bat
```

#### 方法2: 直接実行
```bash
# 基本版
python gui_human_vs_mcts.py

# 改良版
python gui_advanced_human_vs_mcts.py
```

### 操作方法

1. **盤面サイズの選択**: 起動時に盤面サイズを選択（推奨: 15）
2. **石を置く**: マウスで空いているマスをクリック
3. **設定変更**: 右上の設定パネルで各種パラメータを調整
4. **ヒント**: 「ヒント」ボタンでAIの推奨手を表示（改良版のみ）
5. **ゲームリセット**: 「リセット」ボタンで新しいゲームを開始

### 設定パラメータ

#### プレイアウト数
- **範囲**: 100-10000（推奨: 1000-3000）
- **効果**: 大きいほど強いが思考時間が長くなる

#### C_PUCT
- **範囲**: 0.5-3.0（推奨: 1.0-2.0）
- **効果**: 探索と活用のバランスを制御

#### ポリシー（改良版のみ）
- **random**: 完全ランダム選択
- **improved**: 簡単な評価関数による選択

#### 並列スレッド数
- **範囲**: 1-8（推奨: 2-4）
- **効果**: 並列処理による高速化

## AIの特徴

### MCTS (Monte Carlo Tree Search)
- **アルゴリズム**: UCT (Upper Confidence Bound applied to Trees)
- **評価方式**: ランダムプレイアウト + 簡単な評価関数
- **探索方式**: 選択→展開→評価→更新の繰り返し

### 強さの調整
- **弱くする**: プレイアウト数を減らす（100-500）
- **強くする**: プレイアウト数を増やす（2000-5000）+ 改良ポリシー使用

## トラブルシューティング

### よくある問題

1. **「ModuleNotFoundError」エラー**
   - 必要なファイルが同じディレクトリにあるか確認
   - Python環境にnumpyがインストールされているか確認

2. **AIの思考時間が長い**
   - プレイアウト数を減らす
   - 並列スレッド数を増やす

3. **ゲームが固まる**
   - MCTSの設定を確認
   - アプリケーションを再起動

### デバッグモード
コード内で `print` 文を有効にしてデバッグ情報を確認できます。
