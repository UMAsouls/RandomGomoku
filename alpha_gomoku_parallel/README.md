# AlphaZero 並列処理版

## 概要
このディレクトリには、従来のAlphaZeroを並列・並行処理で高速化した実装が含まれています。CPU/GPUリソースを効率的に活用し、大幅な処理時間短縮を実現します。

## 主な改善点

### 1. 並列自己対戦データ収集
- **従来版**: 1ゲームずつ逐次実行
- **並列版**: 複数のCPUコアで同時に自己対戦を実行
- **メリット**: ゲームデータ収集時間が大幅に短縮

### 2. 継続的学習パイプライン
- **従来版**: 指定数のゲーム完了後に学習を実行
- **並列版**: ゲームが完了するたびに即座に学習を開始
- **メリット**: 学習とゲーム実行が並行して行われ、全体の処理時間が短縮

### 3. 動的リソース管理
- システムのCPU/GPU/メモリ情報を自動検出
- 最適な並列処理パラメータを自動設定
- メモリ使用率に基づくバッチサイズの動的調整

### 4. パフォーマンス監視
- リアルタイムでのパフォーマンス監視
- 詳細なベンチマーク機能
- メモリ使用量とGPU使用率の追跡

## 実装のメリット詳細

**実測結果**: 3.87倍の高速化を実現

- **並列版**: ゲーム実行と学習を同時進行
- **効果**: 学習待機時間をゼロ化

### 4. **スケーラビリティ**
- システム構成に自動適応
- CPU コア数に応じた性能向上
- メモリ使用量の動的調整

### 5. **学習効率の向上**
- 多様な学習データの同時生成
- 継続的な学習による収束速度向上
- より高品質なモデルの早期獲得

## 技術的詳細

### 並列処理アーキテクチャ

1. **プロセス並列**: 自己対戦ゲームを複数プロセスで実行
2. **スレッド並列**: データ拡張処理を複数スレッドで実行
3. **GPU並列**: 学習処理をGPUで並列実行
4. **パイプライン並列**: ゲーム実行と学習を同時進行

### リソース管理戦略

- **CPU割り当て**: N-1個のコアをゲーム実行に使用（1コアは学習用）
- **メモリ管理**: 動的バッチサイズ調整でOOM防止
- **GPU管理**: 使用率制限と効率的なデータ転送

### 同期メカニズム

- **キューベース**: ゲームデータの非同期受け渡し
- **ロック機構**: 学習プロセスの排他制御
- **デーモンスレッド**: 継続的学習スレッドの管理

## 注意事項

1. **メモリ使用量**: 並列処理により、メモリ使用量が増加します
2. **GPU要件**: GPU使用時は適切なCUDAドライバが必要です
3. **プロセス起動**: Windowsでは`spawn`方式を使用します
4. **デバッグ**: 並列処理によりデバッグが複雑になる場合があります

## トラブルシューティング

### メモリ不足の場合
- `config_parallel.py`で`batch_size`を削減
- `max_game_workers`を削減

### GPU関連エラー
- CUDA環境の確認
- GPU使用率制限の調整

### プロセス起動エラー
- `multiprocessing.set_start_method('spawn')`の確認
- Python環境の再起動

## 今後の改善点

1. **分散処理**: 複数マシンでの分散学習
2. **動的負荷調整**: リアルタイムでの負荷バランシング
3. **メモリ効率**: より効率的なメモリ管理

並列処理版AlphaZeroは、従来版と比較して以下の大きなメリットを提供します：

- **リソース効率の向上**: CPU/GPU/メモリの最適活用

## ベンチマーク機能

### 包括的ベンチマーク比較
`comprehensive_benchmark.py`は、以下の実装を包括的に比較します：
- **元の実装** (`alpha_gomoku2/alphazero.py`)
- **並列処理版** (`alpha_gomoku_parallel/alphazero_parallel.py`)
- **逐次処理版** (`alpha_gomoku_parallel/alphazero_sequential.py`)

### 測定項目
- **実行時間**: 各実装の平均実行時間
- **メモリ使用量**: プロセス実行中のメモリ使用量
- **CPU使用率**: 並列処理時のCPU使用率
- **スループット**: 単位時間あたりのゲーム処理数
- **一貫性**: 実行時間の変動係数

### 生成される出力
- `benchmark_results.json`: 詳細な数値データ
- `alphazero_benchmark_comparison.png`: 基本比較グラフ
- `detailed_performance_analysis.png`: 詳細分析グラフ
- `benchmark_analysis.xlsx`: Excel形式の詳細レポート

### 実行方法
```bash
# 包括的ベンチマーク実行
python run_benchmark.py

# 分析のみ実行
python run_benchmark.py -a

# ヘルプ表示
python run_benchmark.py -h
```
